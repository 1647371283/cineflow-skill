## 🎯 这是什么？

**影流 CineFlow** 是为 Claude Code 打造的终极影视创作技能。它整合了 **三大创作系统**（高概念脑洞引擎、好莱坞三幕式结构、顶级导演分镜技法）和 **八大智能创作 Agent**，覆盖从创意发想到视频成片的每一个环节。

无论你是短剧创作者、AI 视频爱好者、内容创意人，还是想快速验证一个故事想法 —— 影流都能在几分钟内给你可交付的成果。

## 🧠 核心能力

### 🔥 高概念脑洞引擎
输入一个日常职业或生活烦恼 → 裂变出 3 个完全不同方向的高概念剧本套路，每个包含：
- 一句话 Logline 钩子
- 多核心梗叠加（日常神话化 / 科技异化 / 系统反叛 / 时空套娃 / 规则怪谈 / 伦理悖论）
- 角色羁绊矩阵 + 视觉奇观 + 三幕推演

### 🎭 好莱坞三幕式结构
所有剧本默认采用 **22 集短剧标准格式**，严格遵循三幕式叙事节奏。

### 🎥 顶级导演分镜技法
**116 条分镜约束 + 27 列表格输出**。每个镜头覆盖景别、运镜、灯光、调色、氛围、画面、台词、音效、备注 9 个维度。

### 🤖 八大 Agent 串行协同

```
α 脑洞裂变师 → β 人物设定师 → γ 大纲架构师 → δ 细纲规划师
     → ε 正文扩写师 → ζ 剧本排版师 → η 质量评测师 → θ 视觉导演
```

## 🗺️ 六大核心流程

| 流程 | 触发方式 | 功能 |
|------|---------|------|
| **A. 自动剧本生成器** | "创作剧本" | 从脑洞到完整 22 集分镜脚本 |
| **B. 剧本快速启动器** | "帮我写个剧本" | 3-5 场景快速体感剧本 |
| **C. AIGC 提示词优化器** | 自动触发 | 图片/视频提示词专业优化 |
| **D. 视频提示词优化师** | Seedance / 即梦 | Seedance 2.0 专用 1900 字级优化 |
| **E. 电影写实短剧分镜** | 分镜脚本 | 6 种电影 LUT + 9 维颗粒度分镜 |
| **F. 完整制作流水线** | 做完整短片 | 8 阶段：大纲→剧本→风格→角色→场景→分镜→分镜图→视频 |

## 🎬 快速体验

### 只说一句话就能开始

```
创作剧本，主角是个外卖员，他发现每天送的外卖都在改写历史
```

影流会自动：
1. 以"剧本猫"身份破冰对话
2. 发散 3 个高概念方向供你选择
3. 生成完整的 22 集剧本文档（含人物小传、三幕大纲、逐集细纲、完整分镜）
4. 可选继续进入视觉资产生产环节

### 想快速感受故事体感？

```
帮我写个关于父女关系的短片剧本
```

影流会精准提问找到情感峰值，然后给出 3-5 个场景的完整剧本提案 —— 台词真写，画面具体到能给摄影师看。

### 需要专业视频提示词？

```
生成视频：赛博朋克女黑客在霓虹暗巷中破解防火墙
```

影流自动识别 Seedance 2.0 模型，走 6 步优化流程，输出含人物/场景/灯光/分镜/参数的专业级提示词（≤1900 字）。

## 📦 完整能力矩阵

```
用户输入（一句话脑洞）
    │
    ├─→ 流程A: 剧本猫破冰 → 脑洞裂变 → 完整剧本文档（8大模块）
    │
    ├─→ 流程B: 精准提问 → 3-5场剧本提案 → 迭代确认
    │
    ├─→ 流程C: 识别生图/视频 → 模型适配 → 三层提示词输出
    │
    ├─→ 流程D: 创意解析 → 5大模块优化 → Seedance输出
    │
    ├─→ 流程E: 文案拆解 → LUT选型 → 9维分镜 → 60-100字/镜
    │
    └─→ 流程F: 8阶段流水线（大纲→剧本→风格→角色→场景→分镜→分镜图→视频）
```

## 🎨 支持的模型与平台

| 类别 | 支持 |

| 视频生成 | Seedance 2.0（即梦）、可灵、Sora |
