## 🎯 这是什么？

**影流 CineFlow v2.0** 是为 Claude Code 打造的终极影视创作技能，整合 **三柱创作体系**（念头裂变系统、波浪叙事结构、感官级分镜法则）和 **八位创作智囊**，覆盖从创意发起到视频成片的 **12 条独立创作路径**。

无论你是短剧创作者、AI 视频爱好者、游戏 Demo 制作者、还是想快速验证故事想法——影流都能在几分钟内给你可交付的成果。

## 🧠 三柱创作体系

### 🔥 念头裂变系统
输入一个日常职业或生活烦恼 → 裂变出 3 个完全不同方向的高概念剧本套路，每个包含：一句话钩子、多核心梗叠加（日常升维/技术扭曲/规则裂缝/时间嵌套/认知陷阱/立场困境）、人物张力网、视觉引爆点、三幕推演。

### 🌊 波浪叙事结构
所有剧本默认采用 **22 集标准格式**，以波浪式情绪曲线推动：潮起（铺垫期 1-5 集）→ 暗涌（对抗期 6-17 集）→ 落定（收束期 18-22 集）。

### 🎥 感官级分镜法则
每个镜头只讲一个瞬间但讲到位——单镜单焦点、景别有呼吸、情绪长在身体上、镜头和演员分开说、全片一以贯之。

## 🗺️ 十二大创作路径

### 📜 路径一：剧本锻造
从念头裂变到完整 22 集分镜本，8 大模块（故事种子、精神内核、主角档案、对抗者档案、配角档案、叙事大纲表、逐集细纲、首集分镜本）。

触发：*"创作剧本" + 核心想法*

### ✍️ 路径二：速写剧本
3-5 场戏快速摸到故事体温，精准提问找到情感峰值，台词真写、画面具体到能给摄影师看。

触发：*"帮我写个故事""我想看看故事出来是啥样的"*

### 🔧 路径三：提示词精炼
图片+视频通用，自动侦测生图/视频意图→判定方向型号→画面要素补全→模型适配输出。

触发：*任何生图/生视频动作，自动触发*

### 🎯 路径四：视频提示词锻造（Seedance 2.0）
五大锻造模块（人物全维锁定、场景全维锁定、光影全维锁定、分镜序列、Seedance 专属参数）。

触发：*"生成视频提示词""优化视频 prompt" 等*

### 🎬 路径五：画面级短剧分镜（Seedance 2.0）
六套光影配方（暖茶调/柔花调/逆金调/重彩调/凝眸调/油画调），单镜九项填充，60-100 字/镜。

触发：*"分镜脚本""电影级短剧分镜"*

### 🏭 路径六：全链制作流水线（八道工序）
故事大纲→剧本→画风锁定→角色塑形→场景建置→分镜案→分镜出图→视频合成。

触发：*"做一个完整短片"*

### 🖼️ 路径七：单帧裂片
用户上传一张图 → 画面指纹提取（光影/色彩/材质/动态潜能）→ 分镜表排布（15s/表，7-12镜）→ 提示词编译 → Seedance 2.0 生成 → 剪辑并轨。

触发：*"把这张图做成视频""用这张图生成视频"*

### 🎮 路径八：游戏实机采编
三幕分区（引导流 15s + 剧情流 15s + 战斗流 15s）。GPT 角色设计 → Nanobanan 3D 转换 → GPTImage 场景 → Seedance 视频。

触发：*"游戏演示""做个游戏视频"*

### 📖 路径九：叙事流视频（Seedance 版）
完整故事视频管线：Final_Video_Spec → 故事板（关键元素+镜头列表+音频层）→ 元素生成 → 镜头视频生成 → 音频生成 → 最终组装。

### 🔄 路径十：叙事流视频（底稿直译版）
与路径九流程一致，但视频提示词直接拷贝故事板原文，不另写一套。长镜头+镜内分切设计，六条电影感核心规则。

### 🎥 路径十一：叙事流视频（可灵适配版）
适配 Kling 3.0 Omni 模型，1080p 输出。额外关键帧生成步骤（每镜头一张），Kling 专用提示词写法（主体+运动，背景+运动，相机+运动）。

### 📐 路径十二：分格索引视频（Image2 + Seedance 2.0）
每镜头一张 GPT Image 2 多镜拼版合成图（N 单元格，每格匹配 Seedance 宽高比，剪辑编号标记顺序），Seedance 生成视频。

## 🎬 快速体验

### 用自然语言就能调用

不需要记命令，怎么说都行：

```
我要做个赛博朋克短剧
我想做关于外卖员的视频
帮我写个仙侠故事
用这张图生成一段视频（上传图片）
做个游戏 Demo 演示视频
用可灵做一个故事短片
加分格索引的视频
做个短视频，主角是个失眠的程序员
```

### 只说一句话就能开始

```
创作剧本，主角是个外卖员，他发现每天送的外卖都在改写历史
```

影流会自动：
1. 发散 3 个高概念方向供你选择
2. 生成完整的剧本文档（含人物小传、三幕大纲、逐集细纲、完整分镜）
3. 可选继续进入视觉资产生产环节

### 一图成片

```
帮我把这张图做成一段 30 秒的短片
```

上传一张参考图，影流自动走一图成片流程：视觉基因解构 → 分镜规划 → 提示词构建 → 视频生成。

### 游戏 Demo

```
做个奇幻风格的游戏 Demo 视频，主角是个剑士
```

影流自动三段式拆解（交互→剧情→战斗），GPT→Nanobanan→GPTImage→Seedance 全链路。

## 📦 完整能力矩阵

```
用户输入（一句话/一张图/一个想法）
    │
    ├─→ 路径一：念头裂变 → 8大模块完整剧本 → 首集分镜
    ├─→ 路径二：精准提问 → 3-5场剧本提案 → 迭代确认
    ├─→ 路径三：自动识别生图/视频 → 模型适配 → 三层提示词
    ├─→ 路径四：创意解析 → 5大模块优化 → Seedance 输出
    ├─→ 路径五：文案拆解 → LUT选型 → 9维分镜 → 60-100字/镜
    ├─→ 路径六：8阶段流水线（大纲→剧本→风格→角色→场景→分镜→出图→视频）
    ├─→ 路径七：上传图片 → 画面指纹提取 → 分镜入库 → 视频生成 → 剪辑并轨
    ├─→ 路径八：三幕分区 → 角色管线 → 场景生成 → 三段视频 → 组装
    ├─→ 路径九：制作蓝图 → 故事板 → 元素 → 镜头视频 → 音频 → 组装
    ├─→ 路径十：同路九 → 提示词直接拷贝故事板 → 不另写
    ├─→ 路径十一：同路九 → Kling 3.0 Omni → 1080p → 关键帧
    └─→ 路径十二：故事板 → GPT Image 2 拼版图 → Seedance 生视频
```

## 🎨 支持的工具与平台

| 类别 | 支持 |
|------|------|
| 视频生成 | Seedance 2.0（即梦）、Kling 3.0 Omni（可灵）、Sora |
| 图片生成 | GPT Image 2、Midjourney、Stable Diffusion、DALL-E、Flux、qwen-image-max |
| 角色管线 | GPT 原画 → ImageToImage 四视图 → Nanobanan 3D 转换 |
| 多宫格合成 | GPT Image 2 多镜拼版（带剪辑编号） |
| 风格光影 | 六套光影配方（暖茶/柔花/逆金/重彩/凝眸/油画）|
| 镜头语言 | 感官级分镜法则，覆盖景别/运镜/调度/节奏/焦点 |
